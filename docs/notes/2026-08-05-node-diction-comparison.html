Security Tasks secRemediation.ts

Flow description

The standard security tasks for an incident. These run in this order. Step 3 is requested by either CASA or InfoSec, and completed by Server Ops.

The standard security tasks for an incident. These run in this order. Step 1b is either a user action or Google Admin 'reset sign-in cookies' — InfoSec relays the instruction to CASA. Step 2 covers 'Send As'/alias settings, bad filters, and forwarding rules. Step 3 is requested by either CASA or InfoSec, and completed by Server Ops. Step 4 is a Sophos full system scan, with a re-image requested through TCS if the scan isn't enough.
