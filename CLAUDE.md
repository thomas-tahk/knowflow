# knowflow

Turns knowledge-base text into editable, accessible preset diagrams (flowchart, decision tree, fishbone, step list).

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`thomas-tahk/knowflow`), driven via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using their default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` and `docs/adr/` at the repo root, both created lazily. See `docs/agents/domain.md`.
